# Обновление BSOD Investigator 1.5 → 1.6

1. Закройте старую версию.
2. Распакуйте 1.6 в отдельную папку.
3. Запустите `run.bat` и разрешите UAC.
4. Проверьте заголовок: `BSOD Investigator 1.6.0`.
5. Старую базу `history.sqlite3` **не удаляйте**.
6. Откройте вкладку «История».
7. Посмотрите строку «Ремонт истории». При желании нажмите «Проверить/исправить старую историю».
8. После этого откройте «Мониторинг»: старый `MEMORY.DMP` того же падения не должен увеличивать число уникальных BSOD.
9. Выполните «Анализировать последний dump» и при необходимости соберите ZIP логов для нейросети.

Если у стороннего `.sys` отсутствуют PE-метаданные, версия 1.6 дополнительно пытается определить provider/version/INF/device через установленный драйвер-пакет.
