# Security and diagnostic data

BSOD Investigator работает с системными дампами, журналами событий Windows, путями к файлам, метаданными драйверов и диагностическими отчётами. Часть этих данных потенциально чувствительна.

## Сообщение об уязвимости

Если вы обнаружили проблему безопасности, которая может раскрывать данные пользователя, выполнять неожиданные системные действия или небезопасно обрабатывать внешние данные, не публикуйте технические детали в открытом issue до предварительного контакта.

## Crash dumps

`Minidump` и особенно `MEMORY.DMP` могут содержать фрагменты оперативной памяти процессов и системы. В зависимости от типа дампа там потенциально могут оказаться:

- части документов и текстов;
- пути и имена пользователя;
- данные процессов;
- фрагменты сетевого или прикладного состояния;
- другие сведения, находившиеся в памяти во время сбоя.

Поэтому crash dump не следует автоматически прикладывать к публичному GitHub issue.

## Диагностические отчёты

Перед публикацией отчётов проверьте:

- пути вида `C:\Users\...`;
- имена пользователя/компьютера;
- названия файлов и каталогов;
- имена процессов;
- сведения о конфигурации системы, которые вы не хотите публиковать.

Для большинства баг-репортов достаточно безопасной текстовой сводки и небольшого релевантного фрагмента лога.

## Принцип проекта

Диагностическая система предназначена для поиска первопричины проблемы, но сбор данных должен оставаться минимально необходимым. Runtime-данные, пользовательская история и реальные crash dumps намеренно не входят в репозиторий.
