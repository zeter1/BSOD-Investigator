# Изменения Windows-сборки

- Готовый `BSOD-Investigator.exe` теперь публикуется как постоянный GitHub Release.
- Бинарник собирается из текущего commit и проходит встроенный packaged self-test перед публикацией.
- Рядом с EXE публикуется отдельный файл SHA-256 для проверки целостности.
- README теперь содержит прямую информацию о готовой Windows-сборке и её ограничениях.
- Для глубокого разбора дампов Microsoft `cdb.exe` остаётся внешней зависимостью и устанавливается через Debugging Tools for Windows / Windows SDK.

## Проверка

CI подтверждает сборку и запуск packaged EXE на GitHub-hosted Windows runner. Реальный анализ пользовательских BSOD-дампов и работа с локальной установкой CDB требуют проверки на целевой Windows-машине.
